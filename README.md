# Calculadora de Inferencia Estadística

Aplicación web para calcular intervalos de confianza y pruebas de hipótesis, con gráficas de las distribuciones.

Proyecto final de Estadística, hecho por Julián Hinestroza y Mariana Colorado.

## Funcionalidades

- Intervalos de confianza para una proporción, una media y diferencias de proporciones y de medias (Welch).
- Pruebas de hipótesis Z para proporciones y t para medias.
- Gráficas sombreadas de las distribuciones normal, t, chi-cuadrado y F.
- Comparación entre el intervalo teórico y el real.

## Tecnologías

- Python y Flask
- SciPy
- Matplotlib

## Cómo ejecutarlo

```bash
pip install -r requirements.txt
python main.py
```

Luego abre `http://localhost:5000` en el navegador.
